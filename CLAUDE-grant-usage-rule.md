# Учёт задач Claude Code для отчёта по гранту

> Как подключить: скопируйте раздел «Правило для Claude» в свои личные инструкции Claude Code —
> файл `~/.claude/CLAUDE.md` (локально), или попросите Claude добавить его, или вставьте в начало
> сессии. Не кладите это правило и сам журнал в командные/рабочие репозитории: журнал — личный.
> Заранее создайте свой приватный репозиторий для журнала (например `<ваш-github>/claude-usage-log`)
> и дайте к нему доступ приложению Claude (https://claude.ai/connect-github) — Claude не может
> создать репозиторий сам.

---

## Правило для Claude

Подписка Claude Code используется только для задач, с которыми модели, доступные по гранту,
объективно не справились бы. Если текущая задача такая — добавь запись в журнал самостоятельно, без
запроса подтверждения.

### Классы задач

- архитектура, затрагивающая несколько модулей или сервисов;
- поиск неочевидных причин сложных ошибок;
- задачи, требующие большого объёма контекста;
- задачи, где ошибка может привести к серьёзным последствиям;
- разбор инцидентов и исправление критичных проблем в важных учебных или командных проектах.

Рутинное не записывать: типовой код по известному паттерну, документация, простые исправления,
стандартные SQL-запросы.

### Критерий «объективно не справилась бы»

Сравнивай задачу с параметрами моделей гранта и Claude (параметр `window` не учитывается; `tokenLimit`
трактуется как предел длины одного ответа — укажи это в журнале):

| Модель | Окно контекста | Ответ (tokenLimit) | Рассуждения |
|---|---|---|---|
| **Claude Opus 5.5 / Sonnet 5.5** | **1 млн** | **128 тыс.** | **да** |
| local: Qwen3.8-27B-FP8 (крупнейшее окно среди local) | 250 тыс. | 32 тыс. | да |
| local: Gemma 4 31B / Qwen3.5-35B / Qwen3-VL-8B / Qwen3-32B / Qwen3-Coder-30B / Qwen2.5-72B | 150 / 120 / 80 / 41 / 33 / 16 тыс. | 10–16 тыс. | частично |
| lanit: DeepSeek-V4-Flash, DKS-Lynx, DKS-Vision | 205 тыс. | 10–40 тыс. | частично |
| lanit: DKS-Ultra, Qwen3.5-397B-A17B | 262 тыс. | 40 тыс. | да |
| lanit: GLM-5.3-Flash, DKS-Leo (крупнейшее окно с рассуждениями) | 524 тыс. | 10 тыс. | да |
| lanit: DeepSeek-V4.1-Flash | 1 млн | 40 тыс. | **нет** |
| openrouter: DeepSeek V4 Pro, MiniMax M3, GLM-5.3 — внешние платные API, не локальные | 1 млн / 1 млн / 524 тыс. | 10 / 131 / 16 тыс. | да / да / нет |
| Qwen3-Embedding-8B, BGE Reranker v2 M3, Whisper | — | — | не генерируют код — неприменимы |

Записывай задачу, только если есть проверяемый факт, почему модели гранта не подходят:
- объём контекста больше окна всех local-моделей (250 тыс.), и тогда честно укажи, в какие lanit-модели он
  помещается и чем они уступают (ответ 10 тыс. у GLM-5.3-Flash / DKS-Leo; нет рассуждений у
  DeepSeek-V4.1-Flash);
- или другой проверяемый факт (не «так удобнее»).
Задачу, которая помещается в local-модели, не записывай. В записи укажи, какой Claude использовался
(Opus 5.5 — основная работа, Sonnet 5.5 — вспомогательные агенты).

### Как посчитать объём

Сумма размеров файлов, затронутых задачей, без тестов и локалей; токены ≈ байты / 3 (грубая верхняя
оценка). Для коммита в git:

```bash
c=<хэш коммита>
git show --name-only --format= "$c" | grep -v -e __tests__ -e locales/ | while read -r f; do
  [ -f "$f" ] && wc -c < "$f"
done | awk '{s+=$1} END {printf "%.2f МБ, ~%d тыс. токенов\n", s/1048576, s/3/1000}'
```

### Формат записи

Запись пишется **после завершения задачи** — по фактическому результату. Файл на месяц: `ГГГГ-ММ.md`.
Не сравнивай параметры моделей «в лоб» — сначала задача, потом объективные причины, вытекающие из неё.
Сравнение — только с моделями из списка гранта (таблица выше); локальные — `local/*` и `lanit/*`,
`openrouter/*` — внешние платные API.

```markdown
### ГГГГ-ММ-ДД · ТИКЕТ · Класс задачи

**Задача.** Что было не так или что требовалось — так, чтобы понял человек вне проекта.

**Что сделано.** Фактический результат, без деталей реализации. Сколько файлов затронуто.

**Почему потребовался Claude.** Объективные причины из самой задачи: сколько связанного кода нужно
держать вместе (и что это больше окна локальных моделей из списка), где пряталась причина и почему её
не найти по одному файлу или сообщению об ошибке, какова цена ошибки. Какой Claude работал
(Opus 5.5 — основная работа, Sonnet 5.5 — вспомогательные агенты).
```

Каждое утверждение о моделях должно быть верным для всего списка гранта — проверь по таблице, нет ли
модели, которая его опровергает.

### Куда сохранять

1. Подключи личный репозиторий журнала `<ваш-github>/claude-usage-log` (доступ на запись) и
   склонируй его.
2. Допиши строку в файл текущего месяца (создай файл, если его нет).
3. Закоммить и запушь в `main`.

Никогда не клади журнал в рабочие или командные репозитории.
