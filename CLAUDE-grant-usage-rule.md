# Учёт задач Claude Code для отчёта по гранту

> Как подключить: скопируйте раздел «Правило для Claude» в свои личные инструкции Claude Code —
> файл `~/.claude/CLAUDE.md` (локально), или попросите Claude добавить его, или вставьте в начало
> сессии. Не кладите это правило и сам журнал в командные/рабочие репозитории: журнал — личный.
> Заранее создайте свой приватный репозиторий для журнала (например `<ваш-github>/claude-usage-log`)
> и дайте к нему доступ приложению Claude (https://claude.ai/connect-github) — Claude не может
> создать репозиторий сам.

---

## Правило для Claude

Подписка Claude Code используется только для задач, с которыми модели, доступные по гранту,
объективно не справились бы. Если текущая задача такая — добавь запись в журнал самостоятельно, без
запроса подтверждения.

### Классы задач

- архитектура, затрагивающая несколько модулей или сервисов;
- поиск неочевидных причин сложных ошибок;
- задачи, требующие большого объёма контекста;
- задачи, где ошибка может привести к серьёзным последствиям;
- разбор инцидентов и исправление критичных проблем в важных учебных или командных проектах.

Рутинное не записывать: типовой код по известному паттерну, документация, простые исправления,
стандартные SQL-запросы.

### Критерий «объективно не справилась бы»

Сравнивай с окном контекста моделей гранта (параметр `window` не учитывается):

| Группа | Модель | Окно контекста |
|---|---|---|
| local | Qwen2.5-72B-Instruct | 16 384 |
| local | Qwen3-Coder-30B-A3B | 32 768 |
| local | Qwen3-32B | 40 960 |
| local | Qwen3-VL-8B | 80 000 |
| local | Qwen3.5-35B-A3B | 120 000 |
| local | Gemma 4 31B-it | 150 000 |
| local | Qwen3.8-27B-FP8 | 250 000 — максимум среди local |
| lanit | DeepSeek-V4-Flash-0731, DKS-Lynx, DKS-Vision | 204 800 |
| lanit | DKS-Ultra, Qwen3.5-397B-A17B | 262 144 |
| lanit | GLM-5.3-Flash, DKS-Leo | 524 288 |
| lanit | DeepSeek-V4.1-Flash | 1 048 576 (без режима рассуждений) |
| openrouter | DeepSeek V4 Pro, MiniMax M3 | 1 000 000 |
| openrouter | GLM-5.3 | 524 288 |
| — | Qwen3-Embedding-8B, BGE Reranker v2 M3, Whisper | не генерируют код — неприменимы |

Записывай задачу, только если объём контекста **больше окна всех local-моделей (250 тыс. токенов)**,
или если есть другой проверяемый факт, а не субъективная оценка («так удобнее» — не факт). В записи
честно укажи, в какие модели lanit/openrouter объём всё-таки помещается — ревьюер должен видеть
границы. Задачу, которая помещается в local-модели, не записывай.

### Как посчитать объём

Сумма размеров файлов, затронутых задачей, без тестов и локалей; токены ≈ байты / 3 (грубая верхняя
оценка). Для коммита в git:

```bash
c=<хэш коммита>
git show --name-only --format= "$c" | grep -v -e __tests__ -e locales/ | while read -r f; do
  [ -f "$f" ] && wc -c < "$f"
done | awk '{s+=$1} END {printf "%.2f МБ, ~%d тыс. токенов\n", s/1048576, s/3/1000}'
```

### Формат записи

Файл на месяц: `ГГГГ-ММ.md` в личном репозитории журнала. Одна строка на задачу:

`ГГГГ-ММ-ДД | класс задачи | Jira-тикет (если есть) | что делали; объём (файлов, МБ, ~тыс. токенов) и
каким моделям гранта он не помещается / в какие помещается; при необходимости — последствия ошибки`

Пример:

`2026-10-01 | ошибка с серьёзными последствиями | GOODTLAB-4395 | Ограничили выдачу прав собственным
пулом пользователя для IQE, IDP и проектов; затронуто 26 файлов на 2,17 МБ (~720 тыс. токенов) —
больше окна всех local-моделей (макс. 250 тыс.) и всех lanit-моделей, кроме DeepSeek-V4.1-Flash
(1 млн); ошибка позволяет делегату раздать права, которых у него нет.`

### Куда сохранять

1. Подключи личный репозиторий журнала `<ваш-github>/claude-usage-log` (доступ на запись) и
   склонируй его.
2. Допиши строку в файл текущего месяца (создай файл, если его нет).
3. Закоммить и запушь в `main`.

Никогда не клади журнал в рабочие или командные репозитории.
