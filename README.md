# Учёт задач Claude Code

Журнал задач, для которых используется подписка Claude Code (отчёт по гранту, ежемесячно).
Файл на месяц — `ГГГГ-ММ.md`. Запись делается после завершения задачи и состоит из трёх частей:
задача, что сделано, почему потребовался Claude (объективные причины, вытекающие из самой задачи).

Рутинные задачи (типовой код по известному паттерну, документация, простые исправления, стандартные
SQL-запросы) выполняются локальными моделями и сюда не попадают.

внешние платные API, к локальным не относятся. Таблица используется при оценке, не для прямого
сравнения в записях. Объём кода оценивается как сумма
затронутых файлов без тестов и локалей, токены ≈ байты / 3.
