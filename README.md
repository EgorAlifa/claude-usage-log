# Учёт задач Claude Code

Журнал задач, для которых используется подписка Claude Code (отчёт по гранту, ежемесячно).
Файл на месяц: `ГГГГ-ММ.md`. Формат строки:

`ГГГГ-ММ-ДД | класс задачи | Jira-тикет (если есть) | что делали и почему локальная модель объективно не справилась бы (конкретный факт)`

Классы: архитектура нескольких модулей или сервисов; поиск неочевидных причин сложных ошибок;
большой объём контекста; ошибка с серьёзными последствиями; разбор инцидентов и критичных проблем.
Рутинные задачи не записываются.
